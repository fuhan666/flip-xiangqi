# Flip Xiangqi

翻牌中国象棋本地双人对局。

项目基于标准中国象棋规则，加入“将/帅固定明置，其余 30 枚棋子全局随机暗置、翻牌算一步”的变体玩法。棋盘以标准 9×10 网格做纯 2D DOM 渲染，点击格子完成翻牌与走子。

当前版本已经覆盖：

- Phase 1：项目骨架、规则数据模型、纯规则引擎边界
- Phase 2：随机暗置开局、翻牌动作、回合切换
- Phase 3：全部棋种的标准走法、暗子阻挡、不可直接吃暗子、炮架判定
- Phase 4：将军判定、照将限制、非法自杀着拦截、终局结算
- Phase 5：本地双人交互界面、状态提示、吃子区、重新开局
- 纯 2D 棋盘渲染：标准 9×10 网格、语义化交互按钮与无障碍标签
- 古典视觉呈现：木纹质感棋盘与实木圆形棋子、楚河汉界与九宫斜线、棋位角标、楷体书法棋面（红方帅仕相俥傌炮兵，黑方将士象車馬砲卒）

## 本地运行

```bash
npm install
npm run dev
```

默认打开 Vite 本地地址即可开始对局。

## 测试与构建

```bash
npm test
npm run build
```

构建为标准 Vite + React 流程，不包含 3D 相关依赖、拆包清单或特调的 chunk 警告阈值。

浏览器冒烟与视觉检查（需先 `npm run build`）：

```bash
npx playwright test
```

该套件覆盖多分辨率棋盘几何、暗子脱敏等价、reduced-motion、交互流程与字体渲染取证，截图输出到仓库外的 `evidence/` 目录。

## 交互说明

- 点击暗子：翻牌，消耗整回合
- 点击己方明子，再点击目标格：尝试移动/吃子
- 选中己方明子后，棋盘会标注全部合法落点：空位显示光圈，可吃明子显示外围环（暗子与己方子不会被标注）
- 走子时显示起止点连线轨迹，棋盘持久保留“最后一步”起止高亮环，悔棋后自动恢复
- 吃子时被吃棋子以残影退场，己方将/帅被将军时棋盘外框显示警示波纹与将军警示条
- 非法着法会在右侧状态面板显示原因
- 对局结束后可点击“重新随机开局”或“再来一局”开始下一局

## 体验边界

- 棋盘主区域为纯 2D 渲染（DOM 按钮 + SVG 装饰层，无 3D 场景），保持 9:10 等比缩放、不失真
- 暗子翻开采用 360ms 立体 Y 轴翻转动效，翻转前半程全界面（棋盘、旁栏、历史）严格隐藏棋子身份，过半后才揭示
- 全部动效遵循 `prefers-reduced-motion: reduce`：开启后直接呈现最终状态，无翻转、呼吸、轨迹与波纹动画
- 暗子统一为祥云暗纹木背，未翻开前带轻微呼吸/悬浮动效；`prefers-reduced-motion` 下自动停用
- 暗子翻开前不渲染任何正面棋子信息，仅显示占位「暗」标记
- 仍不包含 legal-move / highlighted-targets 提示（除非后续单独改方向）
- 翻转、走子轨迹、吃子/将军等交互动效留待后续迭代
- 不包含联网、AI、账号体系
