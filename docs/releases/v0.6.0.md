# v0.6.0 版本说明

发布日期：2026-10-16

## 版本定位

`v0.6.0` 是翻牌中国象棋的 **纯 2D 对局体验版本**。本次发布整体移除 Three.js 与 3D 场景，棋盘回归标准 9×10 纯 2D DOM 渲染，在保留全部规则语义的前提下补齐落点提示、动效与交互反馈，并完成全流程回归与发布收口。

## 本次更新

### 1. 纯 2D 棋盘主视图

- 棋盘为语义化按钮网格 + SVG 装饰层（木纹棋盘、楚河汉界、九宫斜线、棋位角标），无 3D 场景
- 保持 9:10 等比缩放、五档视口（1920/1366/1024 桌面与 390/320 移动）不失真
- 棋面为楷体书法文字（红方帅仕相俥傌炮兵，黑方将士象車馬砲卒），暗子翻开前仅显示「暗」占位

### 2. 交互反馈

- 选中己方明子后标注全部合法落点：空位光圈、可吃明子外围环
- 走子轨迹连线与棋盘持久"最后一步"起止高亮环，悔棋后自动恢复
- 吃子残影退场、将军警示条与外框波纹
- 暗子 360ms 立体 Y 轴翻转，翻转前半程全界面（棋盘、旁栏、历史）严格隐藏棋子身份
- 全部动效遵循 `prefers-reduced-motion: reduce`，开启后直接呈现最终状态

### 3. 测试与浏览器回归

- 单元/DOM 测试 14 文件 64 项全量通过，覆盖随机开局（种子可复现、种子差异、禁位约束）、翻牌换回合、走子与吃子规则、炮架判定（0/1/2 个架子）、真实将死与终局后拒绝动作
- 新增 `e2e/game-flow.e2e.ts`：固定种子随机开局后，以合法点击序列完成 翻牌 → 己方走子 → 暗子阻挡/非法操作 → 吃子 → 炮翻山吃子 → 真实将死 → 重开 全链路浏览器验证，关键阶段截图输出至仓库外 `evidence/`
- 既有视觉/无障碍/动效套件（几何、暗子脱敏等价、reduced-motion、键盘、字体取证）保持全绿

### 4. 构建与体积

- `npm run build` 为标准 Vite + React 流程，产物仅 `index.js` + `index.css`，无 Three.js / r3f 拆包与特调 chunk 警告阈值
- 运行依赖仅 `react` / `react-dom`，`npm ls three @react-three/fiber @types/three --all` 为空树
