# v0.9.0 版本说明

发布日期：2026-10-19。

本版交付动作音效、局域网只读旁观、完整棋谱导出与复盘，以及弱网状态恢复。安装后沿用现有本机 Node 宿主和局域网浏览器连接方式，搭建步骤见[局域网联机搭建指南](../lan-setup.md)。

## 对局体验

- 翻牌、走子、吃子、将军及终局使用分层音效，支持音量和静音设置，首次用户手势解锁音频。
- 旁观者可以中途加入，读取当前快照并继续观看；独立恢复身份，掉线不暂停玩家计时或取消协商。
- 本地及联机终局支持复制、下载中文文本和 JSON 棋谱；载入 JSON 后可逐步、跳步或自动只读复盘。

## 弱网恢复

动作 3 秒未确认时获取权威快照：未送达的动作回滚，已提交的动作保留，不重放未确认动作。同步 3 秒无应答转入既有重连。每 5 秒核对局内快照，包含终局，因此只有最终广播丢失、心跳仍畅通时也可恢复。恢复不补播历史音效或动画。

时钟仅采用同局、同 revision 的较新 sampleSeq（相同 sampleSeq 时比较 serverTime）；更高 revision 的时钟触发快照同步，不提前推进棋局版本。旧快照、旧连接消息、旧请求拒绝和已退出对局的迟到状态不会恢复旧主线。显式同步可解除相同 revision 的挂起动作；更高 revision 的合法悔棋可降低步数。

玩家在协商中断线后，服务端取消协商暂停并保留断线暂停；恢复后计时继续，两种暂停期间均不扣局时。手动及自动重连共用在途握手。退避基准为 500/1000/2000/4000ms，每次使用其 80–100% 的随机延迟，分散同时重连。

心跳间隔及应答超时均保持 2000ms。默认参数可容纳本次测试的 100–500ms 应用交付抖动；1999ms 和 2001ms 的应答边界分别验证保持连接和进入恢复。保留 90 秒玩家断线宽限、30 秒协商期限、10 秒求和冷却；大厅恢复预算 20 秒，局内至少 95 秒。浏览器休眠或后台节流会延后计时器，长期失联由宿主权威结算。

消息格式、恢复凭据和协议版本 **6** 保持兼容。本次修复属于消息采用顺序、恢复调度及暂停生命周期，无新增必填字段或破坏性协议迁移；旧版的协议 6 消息仍由同一解析器处理。

## 可重复验证

单元测试使用脚本化 socket 和注入时钟；真实房间测试连接房主、客人与旁观者，将各客户端实际采用的完整局面（包含棋子身份、明暗、坐标、回合和动作历史）、revision、协商、终局和时钟暂停/行动方与服务端快照比较。浏览器测试通过 Playwright WebSocket 路由注入故障，并读取实际客户端状态及界面，无生产调试入口。

WebSocket/TCP 本身可靠且有序。下表的丢弃、重复及乱序均为**应用交付层压力注入**；关闭连接另行验证真实断链。注入日志只记录方向、类型、连接代次、效果及延迟，不记录恢复凭据。

| 场景与参数 | 验证与恢复上限 |
| --- | --- |
| 双向交付延迟 100/300/500ms，动作确认丢弃 | 真实房间 6.5 秒内收敛，并继续下一步；时钟发现缺失 revision 可提前同步 |
| 动作发送前丢弃或断链；提交后确认到达前断链 | 未收到时保持第 0 步、已提交时保留第 1 步，恢复后可继续；动作不自动重放 |
| 动作或拒绝丢失，心跳正常 | 3 秒触发同步；相同 revision 的显式同步清除 pending 并回滚乐观状态 |
| 同步响应丢失、重复同步请求 | 请求合并，3 秒无响应进入重连 |
| 协商完成和最终广播丢失，后续无动作/时钟广播 | 真实房间 6.5 秒、浏览器 8 秒内同步到相同终局 |
| 悔棋/求和中断线，延迟旧回应；协商 30001ms 后回应 | 取消后计时实际推进并继续下一步；超时事件只记录一次；旁观断线保留协商 |
| 重复动作延迟 50/100ms、暂存反向释放、旧 revision/sampleSeq/拒绝/跨局状态 | 历史只提交一次，旧状态不回退；更高 revision 的悔棋可降低步数 |
| 心跳应答 1999/2001ms，旧连接迟到 | 超时边界前保持连接、之后进入恢复；旧连接回调隔离 |
| 三端连续断链 3 轮并连点手动重连 | 每个身份保留单一有效席位；可继续落子；销毁客户端清理恢复定时器 |
| 玩家恢复时间 89999/90001ms（注入服务端时间） | 前者继续对局，后者三端采用相同断线超时终局 |

运行方式（先安装依赖和 Playwright Chromium）：

```bash
npm test -- src/network/__tests__/weak-network.test.ts src/network/__tests__/weak-network-room.test.ts
npm run build
npm run test:e2e -- e2e/online-weak-network.e2e.ts
```

最终发布验证依次执行 `npm test`、`npm run build`、`npm run test:e2e`，全量浏览器套件包含旁观、棋谱复盘、音效与弱网恢复。1366×768、1920×1080、683×768 覆盖对局、断线与重连入口、协商、旁观、终局和复盘。

恢复能力适用于有限故障解除且宿主仍在运行的场景。运行中的房间保存在宿主内存中，重启宿主后需重新建房；公网中继和云端持久化不属于此版本。
