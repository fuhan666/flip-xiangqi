# v0.8.0 版本说明

发布日期：2026-10-19

## 版本定位

`v0.8.0` 是翻牌中国象棋的 **局域网联机实时对战、快捷短语互动与棋谱记录底座版本**。在前序版本构建局域网联机大厅与网络连接保活的基础上，本版本实现了端到端完整的局域网双人实时网络走棋、视角自适应、权威时钟同步与 90 秒断线宽限期、12 条内置快捷短语互动与 5 秒权威频控、局中悔棋/认输/求和协商流程、棋谱动作结构化记录与单步有效思考时间底座，并完成了全端多视口响应式无溢出走查与全量自动化回归。

---

## 本次更新

### 1. 局内内置快捷短语互动

- **12 条内置预置短语**：包含友好问候、精彩赞赏、思考提示与终局礼仪四类精选短语；采用白名单严格校验机制，不支持自由文本输入，杜绝 XSS 与内容违规风险。
- **5 秒权威共享频控**：双端各自独立执行 5 秒冷却倒计时，防止频繁点选刷屏；冷却期间短语按钮处于禁用状态并实时呈现剩余秒数。
- **3 秒气泡浮层与平滑淡出**：发送短语后在自身底栏或对方顶栏侧上方弹出对话气泡，居留 3 秒后平滑淡出；新短语覆盖旧短语，切局或断线时自动清理定时器。
- **无障碍与触控保障**：短语面板入口按钮、弹出项及关闭按钮触控目标均不低于 44×44px，支持键盘 Esc 快速收起与焦点恢复，并支持 `prefers-reduced-motion` 降级。

### 2. 局域网实时走棋与视角自适应

- **权威对局仲裁引擎**：服务端权威校验行棋方、落子规则、暗子阻挡与翻牌动作，双端行棋互斥锁定，彻底防止非法并发着法。
- **红黑视角自适应映射**：无论房主还是客人执红或执黑，双端各自浏览器内己方棋子均居于棋盘下方正向显示，操作坐标自动经由 180° 对称投影双向逆映射。
- **权威局时与步时同步**：支持不计时、快棋（10分+30秒）、标准局（20分+60秒）与慢棋（30分+90秒），服务端 1Hz 权威走秒广播，步时读秒脉动预警。
- **90 秒静默断线宽限**：对手异常掉线时自动暂停对局时钟并展示 90 秒倒计时保护横幅；对手重连后自动恢复对局与时钟，超时则判定掉线方判负。

### 3. 悔棋、认输与求和协商流

- **双向协商互斥弹窗**：局中可发起悔棋或求和申请，对方端弹出 30 秒倒计时应答对话框；协商进行期间双方棋盘操作严格锁定。
- **单步撤销与时钟回滚**：对方同意悔棋后精准回滚最近一步棋，并恢复行棋方对应的时钟检查点；重走后生成唯一新主线记录。
- **防骚扰冷却与认输结算**：求和被拒或超时后触发 10 秒求和冷却；认输二次确认后即刻终局，并触发完整胜负结算弹窗。

### 4. 棋谱对局记录基础设施（为 v0.9 铺路）

- **结构化动作历史（`actionHistory`）**：严格记录每步动作编号 `stepNumber`（从 1 递增）、动作类型 `kind`（`flip` / `move` / `capture`）、棋子坐标及吃子快照。
- **单步思考耗时（`durationSeconds`）**：由时钟模型权威注入每步实际思考时间，剔除暂停与网络等待，为后续棋谱回放提供高保真节奏数据。
- **独立协商事件轨迹（`matchEvents`）**：独立记录申请、应答、拒绝、超时及悔棋协商历史，保证对局过程可完整追溯，且不污染纯走棋着法主线。

### 5. 多视口响应式体验与全量回归

- **多视口无溢出保证**：走查 1366×768（笔记本）、1920×1080（台式显示器）、683×768（半屏分屏）各尺寸，严格保障 `scrollWidth <= clientWidth`，无水平滚动条与布局遮挡。
- **双端全链路自动化套件**：交付 `e2e/online-quick-chat.e2e.ts` 与 `e2e/online-release.e2e.ts`，涵盖开局、翻牌、走子、短语、冷却、协商、终局结算及多视口走查。
- **全量测试全绿**：33 个单元测试文件（273 个测试）与全量 Playwright 端到端套件 100% 通过。
